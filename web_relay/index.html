پس از وارد کردن توکن گیت‌هاب، پیام‌های این اتاق بصورت خودکار دریافت خواهند شد.
فایل‌های انتخاب‌شده جهت ارسال:
میانبر واکشی وب: /web https://example.com 🔓 بدون رمزنگاری E2E
⚙️ تنظیمات رله گیت‌هاب و رمزنگاری
شاخه کاری پیش‌فرض main یا شاخه اختصاصی relay-state
نیاز به دسترسی Contents: Read and write و Actions: Read and write دارد. توکن فقط در حافظه مرورگر شما ذخیره شده و به هیچ سرور دیگری ارسال نمی‌شود.
در صورت عدم انتخاب، توکن تنها تا بسته شدن تب مرورگر در sessionStorage نگهداری می‌شود.
در صورت تنظیم، تمامی پیام‌ها قبل از قرارگیری در گیت‌هاب با الگوریتم AES-256-GCM (PBKDF2 100k) رمزگذاری می‌شوند.
از هدر شرطی ETag استفاده می‌شود تا درخواست‌های بدون تغییر سهمیه API را مصرف نکنند.
🌐 واکشی وب از طریق رانر گیت‌هاب (Web Bridge)
آدرس‌های خصوصی، لوکال‌هاست و رنج‌های ابری توسط گارد SSRF مسدود می‌شوند.
پیش‌فرض ۲ مگابایت برای متن، حداکثر ۵ مگابایت برای فایل باینری.
