### 1. Root Cause & Pre-Remediation CI Failure
- **Pre-Fix Defect:** Prior to commit `38f9cf6`, `.github/workflows/site-chat-read.yml` directly interpolated 5 workflow inputs (`inputs.site`, `inputs.project_url`, `inputs.project_title`, `inputs.job_id`, `inputs.contact`) inside the bash `run:` block of step `Run chat reader (read-only)`.
- **CWE-78 Risk:** GitHub Actions expands `${{ inputs.* }}` expressions textually prior to bash execution. Special shell characters (e.g., quotes, backticks, subshells `$()`, newlines) in user parameters break argument boundaries, creating command injection hazards.
- **CI Gate Failure:** Because `site-chat-read.yml` was not in [Tools/injection_baseline.json](file:///home/runner/work/_temp/agent-repo-45024055198-1-run-agy/Tools/injection_baseline.json), `Tools/check_run_injection.py` flagged all 5 expressions as `NEW`, failing Gate 1 with exit code 1.
