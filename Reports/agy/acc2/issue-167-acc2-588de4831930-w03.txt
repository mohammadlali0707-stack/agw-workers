Formulated the unified offline resilience patch (72 lines, strictly well under the 400-line ceiling) eliminating the curl command-substitution double-emission flaw and secondary alert crashes:

1. **Decoupled Exit & HTTP Code Capture:**
   Replaced the inline subshell fallback `STATUS=$(curl ... || echo "000")` with decoupled execution:
   ```bash
   HTTP_CODE=""
   CURL_EXIT=0
   HTTP_CODE=$(curl -s -S -o /dev/null -w "%{http_code}" \
     -X POST "$EXPECTED_URL" \
     -H "Content-Type: application/json" \
     -d '{"action":"health_check","test":true}' \
     --max-time 10 2>/dev/null) || CURL_EXIT=$?

   if [ $CURL_EXIT -ne 0 ] || [ -z "$HTTP_CODE" ]; then
     STATUS="000"
   else
     STATUS="$HTTP_CODE"
   fi

   echo "HTTP_STATUS=$STATUS" >> "$GITHUB_ENV"
   echo "CURL_EXIT=$CURL_EXIT" >> "$GITHUB_ENV"
   ```
2. **Elimination of Duplicate `'000'` Concatenation:**
   Prevents curl's `000` emission from concatenating with `echo "000"` into `"000000"` or `"000\n000"`.
3. **Reliable `FAIL_TYPE=server_failure` Assignment:**
   Updated the evaluation condition to:
   ```bash
   elif [ "$STATUS" = "000" ] || [ "$CURL_EXIT" -ne 0 ] || { [ "$STATUS" -ge 500 ] 2>/dev/null; }; then
     echo "FAIL_TYPE=server_failure" >> "$GITHUB_ENV"
     echo "FAIL_MESSAGE=HTTP $STATUS (curl exit $CURL_EXIT): Server failure or timeout. The n8n server is down, unreachable, or returning internal 5xx errors." >> "$GITHUB_ENV"
   ```
4. **Secondary Failure Decoupling:**
