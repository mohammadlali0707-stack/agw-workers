In Step 3:
```bash

  -X POST "$EXPECTED_URL" \
  -H "Content-Type: application/json" \
  -d '{"action":"health_check","test":true}' \
  --max-time 10 2>/dev/null || echo "000")
```
1. Upon hitting `--max-time 10`, curl writes `000` to standard output via `-w "%{http_code}"` and terminates with exit code 28.
2. The non-zero exit code triggers the fallback `|| echo "000"`, which writes another `000` to stdout.
3. Subshell command substitution captures both writes, concatenating them into `STATUS="000000"` (length 6).
4. The conditional ladder fails both `[ "$STATUS" = "000" ]` and `[ "$STATUS" -ge 500 ]` (`"000000"` evaluates numerically to 0 < 500).
5. Execution drops into the catch-all `else` branch, setting `FAIL_TYPE=config_error` rather than `FAIL_TYPE=server_failure`.
